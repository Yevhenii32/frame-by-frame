
# Frame by Frame

🌐 **[Переглянути сайт Frame by Frame](https://yevhenii32.github.io/frame-by-frame/)**

**Інтерактивний мультимедійний довідник про будову комп'ютера та принципи роботи його компонентів.**

Навчальний проєкт, розроблений у межах курсу **«Технології мультимедіа»** факультету інформатики Національного університету «Києво-Могилянська академія».

## Про проєкт

**Frame by Frame** — інтерактивний вебдовідник, який допомагає досліджувати будову персонального комп'ютера, принципи роботи його компонентів та розвиток комп'ютерних технологій.

Проєкт поєднує текстові пояснення, інтерактивну графіку, програмні анімації, звуковий супровід, відеоматеріали та навчальні демонстрації.

Користувач може послідовно проходити шість тематичних розділів або самостійно досліджувати компоненти комп'ютера.

## Основні розділи

### 01. Материнська плата
- Інтерактивна схема материнської плати.
- Активні точки для дослідження компонентів.
- Навігація до відповідних тематичних розділів.

### 02. Процесор (CPU)
- Анімована еволюція архітектури процесорів від 1990 до 2026 року.
- Інтерактивний таймлайн із можливістю керування відтворенням.
- Візуалізація структури процесора за допомогою Canvas API.
- Динамічне відображення характеристик різних поколінь.
- Звуковий супровід демонстрації.

### 03. Охолодження
- Інтерактивна демонстрація систем охолодження.
- Порівняння принципів роботи різних типів охолодження.
- Візуалізація температурних показників.
- Звуковий ефект роботи старого кулера.

### 04. Відеокарта (GPU)
- Інтерактивне порівняння растеризації та трасування променів.
- Демонстрація освітлення, тіней і відбиттів.
- Керування режимами графічної візуалізації.
- Пояснення принципів роботи графічного процесора.

### 05. Оперативна пам'ять (RAM)
- Порівняння поколінь оперативної пам'яті DDR.
- Інтерактивне відображення характеристик.
- Пояснення принципів роботи оперативної пам'яті.

### 06. Накопичувачі (HDD / SSD)
- Інтерактивні демонстрації роботи накопичувачів.
- Порівняння технологій HDD та SSD.
- Візуалізація процесів роботи з даними.
- Звуковий супровід роботи жорсткого диска.

## Мультимедійні можливості

### Програмні анімації

Анімації та інтерактивні візуалізації реалізовано засобами JavaScript, Canvas API та CSS.

Основні приклади:
- Еволюція архітектури CPU.
- Демонстрації охолодження та накопичувачів.
- Порівняння графічного рендерингу.
- Анімований фон серверної.
- Світлові імпульси на доріжках мікросхеми.

### Звуковий супровід

Проєкт містить систему звукового супроводу:
- Фонову атмосферу серверної.
- Звук роботи кулера.
- Звук жорсткого диска.
- Супровід анімації еволюції CPU.
- Звукові ефекти взаємодії з інтерфейсом.
- Ефект вимкнення живлення.

Фоновий звук і звукові ефекти можна вмикати та вимикати окремо.

### Відеоматеріали

Тематичні відеоматеріали доповнюють інтерактивні демонстрації розвитку комп'ютерних технологій.

## Навігація та інтерфейс

- Єдиний дизайн шести тематичних сторінок.
- Бокова панель навігації.
- Послідовний сценарій проходження розділів.
- Індикатор прогресу.
- Інтерактивні елементи керування.
- Текстові пояснення та навчальні запитання.
- Окреме керування фоновим звуком і звуковими ефектами.

## Технології

- **HTML5** — структура сторінок.
- **CSS3** — оформлення інтерфейсу та візуальні ефекти.
- **JavaScript (Vanilla JS)** — логіка взаємодії та навчальних демонстрацій.
- **Canvas API** — програмне малювання й анімація графічних об'єктів.
- **Web Audio API** — генерація коротких звукових ефектів.
- **HTML Audio** — відтворення аудіофайлів.

Проєкт реалізовано без використання фронтенд-фреймворків.

## Запуск проєкту

1. Клонуйте репозиторій або завантажте його ZIP-архів.
2. Відкрийте папку проєкту в редакторі коду.
3. Запустіть локальний вебсервер, наприклад за допомогою Live Server у VS Code.
4. Відкрийте `index.html` у браузері.

Для відтворення звуку може знадобитися перша взаємодія користувача зі сторінкою через обмеження автоматичного відтворення аудіо в браузерах.
