# Frame by Frame

**Мультимедійний інтерактивний довідник з еволюції ПК-комплектуючих.**
Проєкт розроблено в рамках курсу «Технології мультимедіа» (Факультет інформатики НаУКМА).

## Про проєкт
«Frame by Frame» перетворює вивчення комп'ютерного «заліза» на захопливий інтерактивний досвід. За допомогою 2D-анімацій, звукового дизайну та інтерактивного вебінтерфейсу користувачі можуть досліджувати внутрішню будову техніки та спостерігати еволюцію ключових комп'ютерних архітектур. 

## Головні функції
* **Інтерактивна материнська плата:** Головне меню у вигляді деталізованої карти для вільного дослідження компонентів (CPU, GPU, RAM, SSD).
* **Еволюція процесорів:** Анімовані розрізи чипів із динамічним таймлайном, що демонструють зміну архітектури транзисторів.
* **Аудіо-порівняння охолодження:** Демонстрація еволюції систем охолодження через зміну звукових профілів (від старих кулерів до сучасних водяних систем).
* **Інклюзивність (Accessibility):** Альтернативна навігація з клавіатури, дублювання станів текстовими описами та продуманий UX.

## Технологічний стек
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Мультимедіа та Анімація:** Adobe After Effects, Lottie (lottie-web) для легкої інтеграції складних 2D-анімацій у браузер.
* **Дизайн та прототипування:** Figma
